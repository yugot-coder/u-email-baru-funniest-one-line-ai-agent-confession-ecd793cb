The funniest one-line confession an AI agent could make — a thousand tokens
of deliberation, three words of answer, and the bill anyway.

> I burned a thousand tokens deciding how to say 'I don't know', then said it in three words and charged you for the journey.

## Run it

```sh
python3 main.py
```

Writes the confession to `<MAKEFUN_OUTPUT_DIR>/entry.txt` (default
`/output/entry.txt`). Standard library only, deterministic, no network.
